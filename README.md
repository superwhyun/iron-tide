# IRON TIDE · 철의 해역

브라우저에서 함선을 직접 조종하고 섬 사이로 기동하며 포격·어뢰·기뢰로 상대를 격침하는 **3인칭 온라인 전술 해전 게임**입니다. 플레이어와 NPC를 합쳐 2–4척이 참가하며, 혼자 NPC와 출항할 수도 있습니다.

월드 오브 워쉽의 항해 관성, 포탑별 사격, 탄종·장갑, 은폐·탐지, 쌍안경 조준에서 영감을 받았습니다. 독자적인 군도 지도와 함종·경기 중 성장 규칙을 사용합니다. 아래 내용은 현재 코드에 반영된 최종 설계와 구현 범위입니다.

![실제 브라우저 전투 화면](artifacts/browser-gun-hit.png)

## 실행과 참가

**Node.js 22.12 이상**이 필요합니다.

```sh
npm install
npm run dev
```

- 게임: <http://localhost:5173>
- 서버 상태: <http://localhost:3000/health>
- 친구와 플레이: **새 함대 창설 → 6자리 코드 공유 → 참가자별 함종 선택·출항 준비 → 함대장 출항**.
- 혼자 플레이: **새 함대 창설 → NPC 함종·모델 선택 → NPC 추가 → 출항 준비 → 출항**. NPC는 자동으로 준비합니다.
- 함대장은 출항 전에 NPC를 추가·제외할 수 있습니다. NPC마다 **지능 1–5**(기본 3)를 고릅니다. 사람과 NPC를 합쳐 최대 4척이며 최소 2척부터 시작합니다.
- 같은 PC에서는 서로 다른 브라우저 프로필이나 시크릿 창을 사용하세요. 재접속 정보는 탭별 `sessionStorage`에 저장합니다.
- 같은 Wi-Fi/LAN에서는 터미널에 표시되는 `Network` 주소를 사용합니다. 방 코드만으로 다른 네트워크에 있는 서버에 접속하지는 못합니다.

### 지갑 로그인 (선택)

대기실의 **지갑으로 로그인**을 누르면 Ronin Wallet·MetaMask 등 브라우저 지갑(EIP-6963 탐색, `window.ronin`·`window.ethereum` 지원)으로 로그인합니다. 로그인하지 않아도 지금처럼 이름만 입력하고 게스트로 플레이할 수 있습니다.

- 게임 서버가 이 페이지 주소·체인 ID·일회용 nonce에 묶인 **SIWE(EIP-4361) 메시지**를 발급하고, 지갑은 `personal_sign`으로 서명만 합니다. 거래나 토큰 사용 승인은 없습니다. 메시지는 5분, 세션은 8시간 유효합니다.
- 서버가 `viem`으로 서명을 검증하고 요청을 한 번만 소비한 뒤 **HttpOnly 세션 쿠키**를 발급합니다. DB에는 토큰 해시만 저장합니다. 상태 변경 요청은 같은 사이트에서 온 것만 받고 로그인 시도는 IP당 분당 20회로 제한합니다.
- 지갑 주소가 곧 계정입니다. 함장 이름과 전적(경기·승리·격침·침몰·피해)이 저장되고, 대기실 명단에 **지갑** 표시가 붙습니다.
- Metanomic 공통 코인 연동의 새 방식(`feat/wallet-game-login` 브랜치 문서)과 같은 게임 자체 로그인입니다. 포털 가입이나 연결 코드가 필요 없고, 보상은 이 지갑 주소(`recipient`)로 지급합니다(아래 관리자 메뉴).

| 환경 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `ACCOUNT_DB` | `data/iron-tide.sqlite` | 계정·세션 저장 파일(Node 내장 SQLite). `:memory:`는 재시작 시 삭제 |
| `GAME_CHAIN_ID` | `2021` (Ronin Saigon) | 로그인 메시지에 넣는 체인 ID |

### 관리자 메뉴와 CGC 보상 지급

대기실 오른쪽 위 **관리자** 링크(`/admin`)가 관리자 콘솔입니다.

- **최초 등록:** 관리자가 없으면 서버 터미널에 `관리자 등록 코드: XXXX-XXXX`가 출력됩니다. 콘솔 첫 화면에 이 코드를 넣고 관리자로 쓸 지갑으로 서명하면 그 지갑이 관리자로 고정됩니다. 코드는 터미널에만 나오므로 서버를 띄운 사람만 등록할 수 있고, 등록 뒤에는 코드가 폐기되어 다시 등록할 수 없습니다. 이후에는 이 지갑으로 서명 로그인합니다.
- **지급:** 지갑 로그인 플레이어 목록이나 최근 경기(1위/참가자 선택)에서 대상을 고르고, 1인당 금액과 사유를 넣어 두 번 눌러 확정합니다. 금액은 소수점 6자리까지 정수 단위로 처리합니다.
- **안전한 전송:** 요청은 먼저 서버 DB에 저장되고, 서버가 3초마다 `POST /games/{gameId}/rewards`로 보냅니다. 요청 키(`rewardRef` = `Idempotency-Key`)가 고정되어 재시작·네트워크 재시도에도 두 번 지급되지 않습니다. 이후 `GET /operations/{id}`로 최종 확정을 확인해 **전송 대기 → 확정 대기 → 지급 완료/실패**로 표시합니다. 실패한 건은 **다시 지급**으로 새 요청을 만듭니다. 단, 요청 참조 충돌(`IDEMPOTENCY_CONFLICT`·`BUSINESS_REFERENCE_CONFLICT`)은 이미 지급이 접수됐을 수 있어 다시 지급을 막고 수동 확인을 표시합니다.
- 게임 예산은 콘솔 상단에 보이며, 최종 한도는 Metanomic 계약이 검사합니다. 게임 API 키는 서버 환경 변수에만 있고 브라우저·로그로 나가지 않습니다. Metanomic을 설정하지 않으면 요청을 저장만 하고, 설정 후 재시작하면 같은 키로 전송합니다.

| 환경 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `METANOMIC_API_URL` | 없음 | Metanomic API 주소(예: `https://…/v1`) |
| `METANOMIC_GAME_ID` | 없음 | 게임 ID |
| `METANOMIC_GAME_KEY` | 없음 | 게임 서버 API 키(비밀) |
| `METANOMIC_ASSET_ID` | `common-game-credit` | 지급할 자산 ID |
| `ADMIN_SETUP_CODE` | 무작위 | 최초 등록 코드를 고정할 때만 사용(테스트용) |

#### 보상 규칙 (자동 지급)

관리자 콘솔의 **보상 규칙** 탭에서 경기가 끝날 때 지갑 함장에게 자동으로 줄 CGC를 정합니다. 기본값으로 바로 동작하며 모든 값은 관리자가 바꿀 수 있습니다.

| 규칙 | 기본값 | 비고 |
| --- | --- | --- |
| 순위 | 1위 5 · 2위 3 · 3위 1 CGC | NPC를 뺀 사람 사이 순위, 지갑 함장 2명 이상일 때. 10위까지 추가 가능 |
| 플레이어 격침 | 1척당 1 CGC | |
| NPC 격침·피해 | 플레이어 보상의 20% × 지능별 비율 (지능 1–5: 10·25·50·75·100%) | 지능 5 격침 0.2, 지능 1 격침 0.02 CGC |
| 피해량 | 피해 10,000당 0.2 CGC | NPC에게 준 피해는 위 비율 적용 |
| 거점 점수 | 100점당 0.3 CGC | 거점전만 |
| 무침몰 보너스 | 1 CGC | 지갑 함장 2명 이상일 때 |
| 참가 | 0.5 CGC | 경기 끝까지 남은 함장 |

- 규칙마다 켜고 끌 수 있고 적용 경기(모든 경기 / 격침전만 / 거점전만)를 고릅니다.
- **지급 조건:** 지갑 함장 1명 이상, 경기 시간 120초 이상. 못 채우면 그 경기는 아무에게도 지급하지 않고 사유를 남깁니다.
- **상한:** 경기당 1인 15, 1인 하루 30, 게임 전체 하루 150 CGC, 0.1 CGC 미만은 지급하지 않습니다. 하루는 서버 시간 자정 기준입니다.
- **예산 보호:** Metanomic 남은 예산이 그 경기 지급액보다 적으면 경기 보상을 **보류**하고, 지급 관리 탭의 최근 경기에서 **보류 지급**으로 승인합니다.
- 한 경기의 보상은 함장마다 한 건으로 합쳐 `iron-tide:match:{경기번호}:{계정}` 고정 참조로 보내므로 재시작·중복 처리에도 두 번 지급되지 않습니다. 계산 내역은 최근 경기 카드에서 볼 수 있습니다.
- **미리보기:** 저장 전에 최근 30경기에 새 규칙을 적용한 결과(총액, 받는 사람, 경기별 내역)를 일일 상한까지 반영해 보여줍니다. 실제 지급은 하지 않습니다.
- 규칙 변경은 다음에 끝나는 경기부터 적용되고, 이미 계산한 경기는 바뀌지 않습니다. 보상 기록이 추가되기 전에 끝난 경기는 계산하지 않습니다.

### 프로덕션 모드

```sh
npm run build
npm start
```

<http://localhost:3000>에서 빌드한 화면과 WebSocket을 함께 제공합니다. `PORT`로 서버 포트를 바꿀 수 있습니다. 개발 모드에서 별도 서버 포트를 쓰면 Vite의 `API_PORT`도 맞춰야 합니다.

방과 경기는 메모리에 저장하므로 서버를 재시작하면 사라집니다. GitHub 저장소에 소스와 자산을 보관하며, 외부 게임 서버 배포는 별도입니다.

## 경기 흐름과 승리 조건

1. 출항 전에 구축함·순양함·전함 중 하나를 선택합니다. 경기 중 함종은 바꿀 수 없습니다.
2. 함대장이 로비에서 **경기 방식**을 고릅니다.
   - **격침전:** 8분 개인전. 격침 수로 순위를 정하고 동점이면 실제 누적 피해량을 비교합니다.
   - **거점전:** 섬 사이 바다의 거점 A·B·C·D(반경 110m)를 차지합니다. 거점 안에 **혼자 8초** 머물면 점령하고, 다른 함선이 함께 있으면 진행이 멈춥니다(교전 중). 보유 거점 하나당 **초당 1점**, 점령 **20점**, 격침 **30점**이며 **600점**을 먼저 따거나 시간 종료 시 최고 점수가 승리합니다. 출격 위치마다 가까운 거점 2곳(약 740m)과 먼 거점 2곳이 있도록 배치했습니다.
3. 결과 화면에서 피해량·명중률·레벨(거점전은 점수)도 확인합니다.
4. 침몰하면 재출격까지 기다립니다. 대기 시간은 그 경기에서 침몰할 때마다 **5 → 10 → 15 → 최대 20초**로 늘어납니다. 재출격 후 **3초간 보호**되며 발사하면 보호가 해제됩니다.
5. 경기 중 얻은 레벨과 강화는 재출격해도 유지됩니다. 다음 경기는 성장을 초기화하고 선택한 함종을 유지합니다.

전투는 정지한 두 배가 같은 거리에서 포탄만 교환하는 방식이 아닙니다. 조준으로 거리와 포신 고각을 바꿀 수 있고, 함선은 관성 때문에 감속·회피에 시간이 걸립니다. 구축함의 은폐 기습, 섬 너머 곡사, 전함의 장갑 각도, 어뢰 진로 유도, 연막·음향 탐지, 기뢰와 수동 요격을 조합합니다.

## 조작과 카메라

화면의 **전투 조작 시작**을 누르면 마우스로 시야와 조준을 조작합니다. 브라우저가 마우스 잠금을 제한하면 창 안의 마우스 이동을 사용하는 대체 입력으로 전환합니다. 한글 입력 상태에서도 물리 키 위치를 기준으로 조작합니다.

| 입력                          | 동작                                             |
| ----------------------------- | ------------------------------------------------ |
| W / S                         | 항속 단계 올리기 / 내리기. 길게 누르면 연속 변경 |
| A / D                         | 누르는 동안 좌현 / 우현 조타                     |
| Q / E                         | 지속 조타. 반대 방향 지속 조타 키로 해제         |
| 마우스                        | 함선 주변 시야 회전·상하 조준, 포탑 추적         |
| 우클릭 유지                   | 기존 주포 조준점을 유지하고 주변 둘러보기        |
| 휠                            | 3인칭 카메라 확대·축소                           |
| Shift                         | 쌍안경 정밀 조준 켜기 / 끄기                     |
| X                             | 조준 방향에 가까운 탐지 표적 지정                |
| 1 / 2 / 3                     | 고폭탄 / 철갑탄 / 어뢰 선택                      |
| 4 / 5 / 6                     | 반철갑탄 / 기뢰 / 대어뢰 로켓 선택               |
| 클릭 / 더블클릭 / 길게 누르기 | 포탑 하나 발사 / 일제사격 / 순차 사격            |
| R                             | 피해 복구: 화재·침수 제거와 잠시 면역            |
| T                             | 구축함 연막 / 순양함 음향 탐지 / 전함 수리반     |
| P                             | 부포 자동 사격 켜기 / 끄기                       |
| Ctrl                          | 커서 해제·강화 패널                              |
| Tab                           | 전투 점수판                                      |
| Esc                           | 마우스 조작 해제·패널 닫기                       |

3인칭 카메라는 함선 주변을 회전하고 거리를 조절합니다. Shift는 망원 시야로 전환하며 **같은 수면 조준 좌표를 유지**합니다. 휠 확대·축소도 조준 좌표를 유지합니다. 일반 시점에서 쏜 뒤 Shift로 확대해 포탄과 착탄을 관찰할 수 있으며, 시점 전환은 이미 발사한 포탄의 궤적을 바꾸지 않습니다.

강화 화면을 닫은 뒤 다시 **전투 조작 시작**을 누르세요. 패널을 열어도 전투와 함선 이동은 계속됩니다.

### 항해·좌초와 탈출

항속은 **후진 → 정지 → ¼ → ½ → ¾ → 전속**의 6단계입니다. W/S를 놓아도 선택한 단계가 유지되며, 실제 속력은 가속·감속 관성에 따라 변합니다. 후진 최고속력은 전진의 30%입니다. 전함은 구축함보다 가속과 선회가 느리므로 미리 항로를 잡아야 합니다.

해안 접촉 시 경고와 서버가 받아들인 기관 명령을 표시합니다. 해안 안쪽으로 파고드는 이동은 막지만, 막힌 추진력의 일부는 **키를 꺾은 쪽으로 해안을 긁으며 미끄러지는 이동**으로 바뀌어 정면으로 박아도 전진 + A/D로 빠져나올 수 있습니다. 해안 접촉 중에는 기관 정지 상태를 포함해 속력과 관계없이 정상 선회율의 70%로 제자리 선회합니다. 가장 빠른 탈출은 여전히 **S를 길게 눌러 후진**하는 것입니다. 해안 안으로 겹친 선체는 바깥으로 복구합니다.

## 조준·탄도와 착탄 분산

마우스 상하 조준으로 수면 목표 거리와 포신 고각을 함께 바꿉니다. 거리를 맞추기 위해 함선을 이동할 필요는 없습니다. 포탄은 서버에서 중력과 비행 시간을 적용해 이동하며 이동 표적에는 앞을 예측해 쏴야 합니다. 섬이나 함선에 먼저 부딪히면 그 지점에서 판정합니다.

수면의 **예상 착탄 원**은 서버가 사용하는 분산 반경을 표시합니다. 포탄은 원 안에서 면적에 균등한 확률로 떨어집니다. 원은 피해 범위나 확정 명중 영역이 아니며 표적이 움직이거나 중간에 지형이 있으면 빗나갈 수 있습니다.

- 함종별 기준 분산 반경은 구축함 8m, 순양함 11m, 전함 16m입니다.
- **포탄 접근 경고:** 적 주포탄이 지금 침로·속력을 유지한 내 함선 위치에 떨어질 것으로 예측되면 "포탄 접근 N초 · 방향"을 띄우고, 내 주변 160m 안의 예상 착탄 지점을 수면에 고리로 표시합니다(내 함선에 맞을 탄은 빨강). 측정상 700m에서 완벽한 리드로 쏜 포탄도 경고 후 변침·변속하면 명중률이 52% → 18%로 떨어지고, 1000m에서는 거의 피할 수 있습니다. 400m 안쪽은 비행 시간이 짧아 사실상 피할 수 없습니다.
- 거리가 멀어질수록 원이 커지고 **최대 사거리의 55%**를 넘으면 증가가 더 가팔라집니다. 이 지점이 최소 분산 거리를 뜻하지는 않으며 가까운 사격의 원이 더 작습니다.
- HE는 기본 분산의 1.12배, AP는 1배, SAP는 0.9배입니다.
- 정확도 강화는 단계마다 기본 반경을 12%씩 줄입니다. 3단계에서는 36% 줄어듭니다.
- 일제 확장은 포탄 수를 늘리는 대신 분산을 단계마다 15% 넓힙니다.
- 강화된 사거리와 무기 종류를 반영하며 사거리 밖 조준은 유효 사거리로 제한합니다.

포탑은 각자 회전 속도·사격 가능 각도·재장전 상태를 가집니다. 선체에 가려진 방향이나 회전이 끝나지 않은 포탑은 즉시 쏠 수 없습니다. HE/AP/SAP를 바꾸면 주포 재장전을 다시 시작합니다. 어뢰·기뢰·RBU로 전환하는 것은 장전된 주포 탄종을 초기화하지 않습니다.

### 기뢰와 대어뢰 방어

**기뢰:** 출격당 3발, 설치 간격 6초, 설치 후 2초에 무장, 수명 90초, 기본 피해 6,000, 폭발 반경 22m입니다. 설치자에게는 피해를 주지 않습니다. 자신이 설치한 기뢰는 보이며 적의 기뢰는 110m 근접 탐지 또는 음향 탐지 등 탐지 조건에 따라 보입니다.

**RBU:** 출격당 6회, 재사용 10초, 최대 사거리 240m입니다. 6발이 시간차로 날아가 착수 지점 주변 22m의 적 어뢰·기뢰를 제거하고 함선에는 작은 범위 피해를 줍니다. 자동 추적 포탑이 아니므로 어뢰의 접근 방향과 로켓 도달 시간을 읽어 수역을 선점해야 합니다. 자신의 어뢰·기뢰는 제거하지 않습니다.

기뢰·로켓 탄수는 재출격 때 보충합니다. 설치자당 동시에 유지하는 기뢰는 최대 3개이며 추가 설치 시 가장 오래된 것을 교체합니다. 기존 기뢰는 수명·폭발·경기 초기화 규칙에 따라 정리합니다.

## 충돌·장갑과 명중 피드백

서버가 포탄의 이전 위치부터 다음 위치까지 **연속 3D 구간**으로 가장 먼저 접촉한 표면을 찾습니다. 단순히 선체 외곽 사각형 안에 들어왔다는 이유만으로 명중시키지 않습니다.

- 플레이어 함선의 곡면 선체와 갑판은 렌더링과 충돌이 같은 기하 정의를 공유합니다. 상부 구조물·추가 포탑은 별도 단순 충돌체입니다.
- NPC는 제공된 원본 GLB의 노드 변환·삼각형을 읽고 화면과 같은 회전·크기·수면 높이로 정규화합니다. BVH로 표면 교차를 찾습니다.
- 접촉점의 법선과 선수·함미·측면·갑판·상부 구조물·포탑 부위를 장갑 판정에 사용합니다. 상부 구조물에 중장갑 측면 수치를 일괄 적용하지 않습니다.
- 측면은 수선부 **주장갑대**(흘수선부터 갑판 높이의 30%까지)와 그 위의 얇은 **상부 측면**으로 나눕니다. 고폭탄은 상부 측면을 노려 피해와 화재를 내고, 핵심 구획은 주장갑대를 관통한 철갑탄으로만 납니다.
- AP는 입사각과 얇은 장갑에 대한 구경 우세를 반영합니다. 순양함·전함의 핵심 구획과 과관통을 구분합니다. 핵심 구획 명중은 포탄 피해의 60%(관통 33%, 과관통 10%)입니다. 실제 표면에 맞아도 도탄·비관통이면 체력 피해가 없을 수 있습니다.
- 파도의 작은 시각적 흔들림, 모든 난간·장식·추가 포신까지 물리적으로 복제하지는 않습니다.

**조준 장갑 예측:** 표적을 지정(X)하거나 조준점 120m 안에 적이 있으면 조준경 아래에 현재 포탄의 측면·선수·상부 구조물 예상 판정(관통·과관통·비관통·도탄)과 측면 입사각을 표시합니다. 측면을 뚫지 못하면 관통 가능한 탄종이나 어뢰를 권장합니다. 서버와 같은 장갑 공식(`shared/armor.ts`)을 쓰는 수평 근사이며 갑판 낙하 판정은 제외합니다. 예: 순양함 203mm 철갑탄의 관통력 254mm는 전함 측면 260mm를 뚫지 못합니다.

**명중 확인과 피해를 분리**합니다. 조준점 명중 마커, 대상 근처의 피해 숫자, 일제사격 합계, 최근 명중 기록을 함께 표시하고 관통·과관통·핵심 구획·도탄·장갑 비관통·재출격 보호 사유를 구분합니다. 장갑 판정에는 접촉 부위·두께·입사각도 표시합니다.

피해 숫자는 **72px**, 등장 시 확대 연출을 적용하고 **3초간 유지**합니다. 추가 피해는 기존 숫자를 지우지 않고 **그 위에 중첩**합니다. 같은 순간의 같은 판정만 합산하며, 피해량에 따라 연노랑·주황·빨강으로 구분합니다. 큰 피해와 핵심 구획 명중은 더 강하게 강조합니다. 피해 없는 명중은 별도의 작은 문구로 나타냅니다.

## 지형·은폐와 탐지

군도는 9개 섬과 불규칙한 해안·능선으로 구성합니다. 화면과 서버가 같은 해안·지형 함수를 사용합니다. 섬은 이동과 일반 시야를 막지만 충분히 높은 탄도의 포탄은 섬 위로 날아갈 수 있습니다.

- 기본 피탐지 거리는 함종마다 다릅니다. 주포 발사 후 **20초간** 피탐지 거리가 현재 주포 사거리까지 늘어납니다.
- 화재는 노출을 늘립니다. 연막은 양방향 시야를 제한하지만 연막 안 발포에는 별도의 노출 규칙이 있습니다.
- **100m 이내 강제 탐지**와 순양함의 **430m 음향 탐지**가 있습니다. 음향 탐지는 섬·연막 뒤의 가까운 표적도 드러냅니다.
- 표적을 놓치면 현재 좌표 대신 마지막 목격 위치를 미니맵에 표시합니다.
- 서버는 미탐지 적의 현재 좌표·체력·레벨을 상대에게 전달하지 않습니다.

**부위 손상:** 실제 피해를 준 포탄·어뢰는 부위를 고장 낼 수 있습니다(부포 제외, 한 발에 한 부위).

| 화력 증폭 | 20초간 주포 포탄 피해 +25% |

| 응급 수리 | 즉시 최대 체력 20% 회복, 화재·침수 진화 |

**T · 특수 장비:** 함종마다 3회 사용할 수 있고 재사용 60초입니다.

| 함종   | 특수 장비                                          |
| ------ | -------------------------------------------------- |
| 구축함 | 12초간 연막을 생성. 각 연막은 반경 100m, 32초 유지 |
| 순양함 | 25초간 수중 음향 탐지                              |

수리반은 모든 피해를 원상 복구하지 않습니다. 화재·침수 피해는 100%, 일반 피해는 50%, 핵심 구획 피해는 10%를 회복 가능량으로 적립하며 그 범위 안에서 회복합니다.

## 경기 중 성장과 강화

실제 입힌 피해량만큼 경험치를 얻고 격침 시 500, 격침자가 아닌 참가자가 표적 최대 체력의 10% 이상 피해를 기여하면 250의 추가 경험치를 받습니다. 다음 레벨 필요 경험치는 `1,600 + (현재 레벨 - 1) × 900`이며 최고 **레벨 10**, 레벨업마다 강화 포인트 1점입니다.

각 강화는 최대 3단계입니다. 수치는 단계당 기본값 대비 변화이며 다른 종류의 강화 효과는 함께 적용됩니다.

| 강화               | 효과                                     |
| ------------------ | ---------------------------------------- |
| 사격 관제 · 정확도 | 주포 분산 반경 −12%, 3단계에서 −36%      |
| 주포 사거리        | 사거리 +8%. 발포 피탐지 거리도 증가      |
| 일제사격 포탄 수   | 포탑당 포탄 +1, 분산 +15%, 포탄 피해 −8% |
| 주포 재장전        | 재장전 시간 −7%                          |
| 부포 성능          | 사거리 +10%, 재장전 시간 −10%            |
| 어뢰 성능          | 속도 +8%, 재장전 시간 −6%                |
| 기관과 조타        | 최고속력 +5%, 가속·선회 +6%              |

침몰해도 레벨·강화는 유지하고 다음 경기에서 초기화합니다. 장비가 없는 함종은 해당 무장 강화에 제한이 있습니다.

## NPC와 사용자 제공 함선

NPC는 일반 플레이어와 같은 서버 규칙으로 이동·탐지·피해·재장전·재출격·강화를 처리합니다. 섬과 경계를 피해 항로를 탐색하고, 탐지한 적에게 예측 포격·어뢰 공격을 하며 위협을 회피합니다. 특수 장비, 근접 기뢰, 대어뢰 로켓도 사용합니다. 미탐지 적 좌표를 조준 정보로 사용하지 않습니다.

| 지능 | 판단 주기 | 리드 오차 (속력 / 침로) | 조준 산포 | 교전 거리 | 장비 사용 |
| ---- | --------- | ----------------------- | --------- | --------- | --------- |
| 1    | 0.9초     | ±70% / ±29°             | 거리의 5%   | 사거리 60% | 회피·피해 복구·특수 장비·어뢰 없음 |

## 시각·침몰 연출

플레이어 함선은 곡면 선체, 목재 갑판, 함교 창, 난간·마스트·장비와 포탑을 갖춥니다. 섬은 연속적인 능선과 해안에 사진 기반 암벽·모래·식생 재질을 혼합하고 해안에는 밀려드는 파도 거품 띠를 그립니다.

하늘은 오후의 낮은 태양·대기 산란·움직이는 구름을 절차적으로 그리고, 같은 하늘로 반사 환경을 만들어 강철·유리에 반영합니다. 수면은 다중 너울·잔물결 법선, 프레넬 하늘 반사, 태양 반짝임, 파도 마루의 산란광과 흰 물결, 수평선 안개를 하나의 셰이더로 계산합니다. 그림자는 내 함선 주변을 따라다니며 선명하게 유지합니다. 렌더링은 HDR 후처리(블룸·색 보정·비네트·필름 그레인·피격 색수차)를 거칩니다. SwiftShader 같은 소프트웨어 렌더러를 감지하거나 일반 GPU에서도 프레임이 계속 24fps 아래면 저사양 모드로 전환해 후처리를 생략하고(같은 톤 매핑으로 직접 렌더링) 하늘·수면 셰이더와 입자 수를 줄입니다.

포탄에는 탄체, 빛나는 예광 탄두와 짧은 궤적, 발사 시 포신 방향 화염 분출·포연·포탑 반동을 적용하고 대구경은 함 옆 수면에 폭압 파문을 만듭니다. 착수는 구경에 따라 솟구쳤다 무너지는 물기둥·물보라·물방울 왕관·수면 안개·오래 남는 거품 자국으로 표현합니다. 함선 명중 시 피해에 비례해 섬광·충격파·불덩이·불꽃·튀는 파편(수면에 닿으면 작은 물보라)·검은 연기를 만들고, 핵심 구획 명중은 뒤이은 2차 폭발과 화염 분출을 더합니다. 같은 일제사격이 한곳에 몰리면 섬광을 줄여 화면이 하얗게 날아가지 않게 합니다. 도탄·비관통은 불꽃만 튑니다. 화재 중인 함선은 계속 불길과 검은 연기 기둥을, 체력이 낮은 함선은 회색 연기를 내며 항주 중에는 선미 거품 항적과 선수 물보라가 남습니다.

**타격감:** 내 주변 착탄·내 함선 피격·근처 격침은 거리와 위력에 비례해 화면을 흔듭니다. 주포 발사 시 반동으로 시야가 살짝 튀고, 피격 시 붉은 테두리·색수차·HUD 흔들림, 가까운 착탄에는 렌즈 물방울이 맺힙니다. 체력이 30% 아래면 화면 가장자리가 붉게 맥동합니다. 흔들림은 렌더링에만 적용하므로 조준 좌표와 탄도에는 영향을 주지 않으며, 쌍안경 시야에서는 배율에 맞춰 흔들림을 줄이고 화면을 가리는 가까운 연기·파편은 투명하게 합니다.

**전투 HUD:** 하단 좌측 함선 상태(눈금 체력 막대·체력 경고 색), 미니맵 옆 무장 선택판, 상단 방위 나침반(시선 방위·내 함수 방향 표시), 거리 눈금이 있는 조준경, 표적 태그로 구성합니다. 무장판을 미니맵 옆으로 옮겨 3인칭 시점에서 내 함선이 가려지지 않습니다.

최종 침몰은 폭발 후 **원본 선체를 중앙에서 두 부분으로 나눠** 파손 단면과 내부 골조를 드러냅니다. 두 부분이 독립적으로 벌어지고 기울며 내려가고 갑판 화염·연기·증기를 더합니다. GLB의 원래 외형과 재질도 유지합니다. 약 **13초간** 진행하는 시각 연출이며 재출격 5초 규칙과 독립적입니다. GPU 클리핑·애니메이션 방식이며 물리적인 선체 파괴·유체 해석은 아닙니다.

## 엔진·무기 음향과 무전

대기실의 **주포 시연 · 음향 듣기**에서 포탑 반동·포연·탄도와 포성을 미리 확인할 수 있습니다. 음량 슬라이더와 전체 음향 ON/OFF, 무전 ON/OFF를 제공합니다. 브라우저 오디오 활성화를 위해 사용자 클릭이 필요합니다.

- **포성:** 실제 함포·대포·폭발 녹음을 섞고 저음과 잔향을 적용합니다. 거리별 감쇠·필터·전파 지연과 좌우 위치를 반영하고 출력 리미터를 사용합니다.
- **항해음:** 실제 속력·기관 부하에 따라 엔진음의 높이·음량이 변하며 속력이 붙으면 선수 물살이 커집니다. 후진도 반영하고 침몰·퇴실·접속 단절 시 잦아듭니다.
- **어뢰:** 압력 방출과 3발의 입수음을 별도로 재생합니다. 실제 어뢰 녹음 대신 압력·물소리 Foley를 사용합니다.
- **착수:** 실제 물소리 녹음과 저음·거리 감쇠를 물기둥에 맞춰 재생합니다.
- **무전:** 가속·감속·정지·후진·좌현·우현·키 중앙 명령에 한국어 남성 음성과 자막을 사용합니다. `ko-KR-InJoonNeural`로 미리 생성한 12개 WAV에 무전 대역 필터·압축·약한 잡음·송수신음을 적용했습니다. 배우나 실제 군 교신 녹음은 아닙니다.
- 키를 유지해도 같은 무전을 반복 호출하지 않습니다. 빠르게 바꾼 명령은 기관·조타별 최신 명령으로 정리하며 음성이 겹치지 않도록 순서대로 재생합니다.

모든 재질·GLB·녹음·무전은 로컬 파일로 제공합니다. 플레이 중 외부 음성 API나 운영체제 TTS를 호출하지 않습니다.

## 온라인 구조와 연결 처리

TypeScript와 Three.js/Vite 프런트엔드, Node.js/WebSocket 서버를 사용합니다. 서버가 **30Hz**로 시뮬레이션하고 참가자별 필터링한 상태를 **15Hz**로 전송합니다. 피해·충돌·장갑·탐지·경험치·강화·무장 사용 가능 여부는 서버가 판정합니다.

재접속 토큰은 서버가 무작위로 발급하며 공개 점수판에 넣지 않습니다. 연결이 끊겨도 함선은 기존 항속·조타를 유지하고 공격받을 수 있습니다. **30초 안에** 자동 재연결이나 새로고침으로 복귀할 수 있습니다. 함대장이 나가면 연결된 사람 참가자에게 권한을 넘깁니다. 사람이 없는 방은 정리하며 NPC가 함대장이 되지는 않습니다. 이름 등 외부 문자열은 화면에 표시할 때 HTML 이스케이프합니다.


**2026-10-18 최종 검증:** 빌드·TypeScript 검사, 단위·WebSocket 통합 테스트 **55개**, 브라우저 시나리오 **10개** 모두 통과했습니다.

## 현재 범위와 후속 과제

현재 버전은 로컬 서버를 통한 2–4척 개인전입니다. 월드 오브 워쉽의 정확한 수치·실함·장갑 도면·국가별 연구 계통을 복제하지 않습니다. 역사적 함선의 정밀 복원이나 실물 군사 시뮬레이션 수준은 아닙니다.

항공모함·잠수함·팀전·계정·영구 성장·공개 매칭·외부 서버 배포는 구현하지 않았습니다. 다른 실제 PC에서의 LAN/인터넷 교전과 일반 GPU의 1080p·60fps는 미검증입니다. 자동 브라우저 검증은 소프트웨어 렌더링 환경에서 수행했으며, 해당 측정과 일반 사용자 GPU 성능을 구분합니다.
